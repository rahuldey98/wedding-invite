# 💍 Rahul & Riya — Wedding Invitation Website

A digital wedding invitation website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**, optimized for 100% free hosting on **GitHub Pages**.

---

## ✨ Features

- **💌 Interactive Envelope Unboxing**: Realistic watercolor floral theme with rose wax seal stamp.
- **👑 Customized Heritage Invitation Card**: Lush palm leaves, parents' invitation, vibrant magenta calligraphy script, and detailed Kolkata landmarks skyline.
- **✨ Interactive Scratch-to-Reveal Card**: Golden scratch card uncovering a surprise photo on drag/swipe.
- **⏳ 4-Column Divider Countdown**: Counting down to 29th January 2027 with Days, Hours, Minutes, and Seconds.
- **📅 Events Schedule Timeline**:
  - **Aiburobhaat**: 28th January at 12:00PM
  - **Gaye Holud**: 29th January at 11:30AM
  - **Wedding**: 29th January at 7:00PM
  - **Reception**: 31st January at 7:00PM
- **📍 Venue & Navigation**: Kolkata Sector V map linked to Google Maps.
- **🕊️ Blessings & Love Note**: Warm blessings closing with `#rahul&riya`.

---

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build static export for production
npm run build
```

---

## 🌐 Deploying to GitHub Pages

1. **Push your code to GitHub**:
   ```bash
   git add .
   git commit -m "feat: wedding invitation for Rahul & Riya"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub $\to$ **Settings** $\to$ **Pages**.
   - Under **Build and deployment** $\to$ **Source**, choose **GitHub Actions**.
   - Your site will be automatically deployed at `https://<YOUR_USERNAME>.github.io/<YOUR_REPOSITORY>/`.
